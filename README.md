# Doctrinex Settings

Package: `com.eno.doctrinex`

Features:
- Settings namespace selector: global, secure, system
- Command preview and clipboard copy
- Shizuku execution
- Root execution through libsu
- Java + XML Android project

## Important
- Shizuku must be installed, started, and authorized.
- Root execution requires a rooted device and an available `su` service.
- Android restricts many `secure` and `global` keys. A successful process does not guarantee that a particular key can be changed.
- Test commands carefully. Avoid changing unknown keys or resetting system settings.
